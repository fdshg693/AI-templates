# スレッド実行中の追記

スレッドに所属するプランを実行している間に、事実の発覚・仕様変更・手戻り・プランの追加・順序変更が起きたときに読む。書式（`log.md` のエントリ・種別・`plans:`）の正本は [thread-writing.md](thread-writing.md)。

## 何をどこに書くか

スレッドには**プラン横断の事実と判断**だけを書き、1つのプランの中で閉じる詳細は plans の規則どおりプランと progress に書く。

| 情報 | `log.md` | `00-thread.md` | 所属プラン |
| ---- | -------- | -------------- | ---------- |
| 1つのプランの中で閉じる事実・差分・実装メモ | 書かない | — | 本文と progress（plans の規則） |
| 実行中のプラン以外にも影響する事実 | `[発見]` 1〜3行＋反映先リンク | 必要なら `未解決事項` | 影響する全プランの本文を直接更新 |
| 要求・スコープの変更 | `[仕様変更]` | `目的・スコープ` を書き換え | 影響する全プランの本文を直接更新 |
| 完了済みプランのやり直し | `[手戻り]`（原因と、元のプラン・新しいプランへのリンク） | `plans:` と `プラン一覧` に新しいプランを追加 | 新しいプランを作る。元のプランの `status` は戻さない |
| プランの追加 | 原因の種別（無ければ `[計画]`） | `plans:` と `プラン一覧` に追加 | `thread:` を足す |
| 予定順・着手条件の変更 | `[順序変更]` | `plans:` と `プラン一覧` を並べ替え | `order` / `depends_on` / `blocks` を両端で更新 |
| 中断・再開（`open` ⇔ `paused`） | 書かない | `status` と `未解決事項`（再開条件） | — |
| 所属プランの完了 | 書かない（クローズ時にまとめて書く） | — | 完了記録（plans の規則）。**削除しない** |

所属プランへの反映は `log.md` より先に済ませる。理由: plans の不変条件「予定外の事実は影響プラン本文へ直接反映する」を守り、後続の実行者がスレッドを読まなくても次の作業を判断できるようにする。

## 手順

1. 起きたことを上の表に当てはめ、`log.md` に書くかどうかを決める。書かない場合は plans の規則だけで進める。
2. 影響する所属プランの本文（「やること」「触るファイル」「決定事項」など）と frontmatter を、plans の規則どおり更新する。着手済みプランの `snapshot/` は触らない。
3. `00-thread.md` を更新する。
   - プランを足すときは、プランの `thread:`・スレッドの `plans:`・`プラン一覧` の3か所を同時に更新する。
   - 並び替えるときは `plans:` と `プラン一覧` を同じ順にする。同じスレッド内で A が B に `depends_on` するなら B を前に置く。
   - プランを外すとき（別スレッドへの移動・単独プラン化）は、`plans:`・`プラン一覧`・プランの `thread:` を同時に外す。
4. `log.md` の末尾にエントリを1つ追記する（`## YYYY-MM-DD [種別] 見出し`、1〜3行、反映先リンク）。過去のエントリは書き換えない。
5. lint を実行する。

## スレッドが `open` / `paused` の間の追加ルール

plans の「完了後の後片付け」に対する追加ルールで、所属プランについては threads 側を優先する。

- 所属プランが `implementing-done` になっても、プランのフォルダ・ファイルを削除しない。理由: `plans:` のリンクが切れ、作業中に完了済みプランへ辿れなくなる。削除はクローズ時に一括で行う（[thread-closing.md](thread-closing.md)）。
- 完了記録・`status`・チェックボックスの更新は plans の規則どおり行う。

## 完了条件

- [ ] 影響する所属プランの本文が更新され、`log.md` の末尾に該当エントリがある（書く場合）
- [ ] `plans:`・`プラン一覧`・各プランの `thread:` が一致している
- [ ] リポジトリのルートで次がエラー0で終わる

  ```bash
  uv run threads/lint_threads.py threads
  uv run threads/planning/lint_plans.py threads/planning
  ```
