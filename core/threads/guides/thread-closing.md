# スレッドのクローズ

所属プランがすべて完了したとき（`closed`）、または途中で作業をやめると決めたとき（`abandoned`）に読む。書式の正本は [thread-writing.md](thread-writing.md)。

このファイルの後片付けは、plans の「完了後の後片付け」に対する追加ルールで、所属プランについては threads 側を優先する。スレッドが `open` / `paused` の間に保留していた所属プランの削除を、ここで一括して行う。

## 作るもの

- `log.md` の末尾に、所属プランごとの `[完了]` エントリと、最後にスレッド全体の `[完了]` エントリ。プランを削除した後は、このエントリが唯一の記録になる。
- `00-thread.md` の `status: closed`（または `abandoned`）、`plans: []`。
- スレッドのフォルダ `topics/{thread-name}/` は削除せず、記録として残す。

## 手順（`closed`）

1. `plans:` の全プランが `implementing-done` で、plans の規則どおり完了記録があることを確かめる。未完了のプランがあればクローズしない。
2. `log.md` の末尾に、所属プランごとに `## YYYY-MM-DD [完了] {plan-name}` を追記する。本文は1〜3行で、完了した範囲・検証結果・計画との差分の有無（完了記録の要約）を書く。プランは次の手順で削除するので、プランへのリンクは張らない。
3. 最後に `## YYYY-MM-DD [完了] スレッドをクローズ` を追記し、スレッド全体の結果と、持ち越した事項の行き先（新しいスレッドやプラン）を書く。
4. `00-thread.md` を更新する。
   - `status: closed`、`plans: []`。
   - `プラン一覧` は「なし（各プランの完了要約は log.md）」の1行にし、`log.md` へリンクする。
   - `未解決事項` は持ち越し先を書くか「なし」にする。
5. 各プランの `thread:` を外し、plans の「完了後の後片付け」の3・4（プランの削除と参照の除去）を行う。スレッド外のプランと `depends_on` / `blocks` でつながるプランは、plans の規則どおり削除を保留する（`thread:` は外したまま、単独プランとして残る）。
6. lint を実行する。

## 手順（`abandoned`）

1. 所属プランを1つずつ、次のどれにするか決める。
   - `implementing-done` のプラン → `closed` と同じく削除する。
   - 未完了のプラン → 「削除」か「`thread:` を外して単独プランとして続ける」のどちらか。
2. `log.md` の末尾に、所属プランごとに `[完了]` エントリを追記し、どれを選んだかと理由を1〜3行で書く。単独プランとして続けるプランにはリンクを張ってよい（削除しないため）。
3. 最後に `## YYYY-MM-DD [完了] スレッドを中止` を追記し、中止の理由を書く。
4. `00-thread.md` を `status: abandoned`、`plans: []` にし、`プラン一覧` と `未解決事項` を `closed` と同じ形にする。
5. 削除するプランは `closed` の手順5と同じく後片付けする。続けるプランは `thread:` を外すだけにする。
6. lint を実行する。

## 守ること

- `log.md` の過去のエントリにある、削除したプランへのリンクは書き換えない。理由: `log.md` は追記のみ。`lint_threads.py` は `closed` / `abandoned` のスレッドの `log.md` ではリンク切れを検査しない。
- `closed` / `abandoned` のスレッドを `open` に戻さない。関連する作業が後で出てきたら新しいスレッドを立て、`目的・スコープ` から古いスレッドへリンクする。理由: クローズ時に所属プランを削除しているため、戻しても辿れるプランが無い。

## 完了条件

- [ ] `00-thread.md` が `status: closed` / `abandoned` で `plans: []`
- [ ] `log.md` の最後のエントリが `[完了]` で、所属プランごとの `[完了]` エントリがある
- [ ] 削除したプランへの参照が、他のプランの `depends_on` / `blocks` に残っていない
- [ ] リポジトリのルートで次がエラー0で終わる

  ```bash
  uv run threads/lint_threads.py threads
  uv run threads/planning/lint_plans.py threads/planning
  ```
