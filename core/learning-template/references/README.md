# {domain} 学習レポジトリ

`{domain}` に関する学習をまとめるリポジトリ。

- [`study/`](./study)
    - `{domain}` の各テーマについて、実装して試しながら学ぶフォルダ。
    - テーマごとにプロジェクトが分かれ、各プロジェクトでコードや作業を通して学習を進める。
    - 徐々にプロジェクトを難しくしていき、段階的に理解を深める。

- [`reading/`](./reading)（任意）
    - 実装せず、座学として概念を整理するフォルダ。
    - 実装・検証は `study/` 側で行う。

- [`sandbox/`](./sandbox)（任意）
    - 外部の有料リソースやクラウド環境を使わず、ローカルだけで完結する検証を置くフォルダ。

- [`build/`](./build)（任意）
    - 学習の枠を超えて、実際に使いたいものを本気で作るフォルダ。
    - `study/` の標準構成をベースにしつつ、自由度を認める（詳細は [`build/AGENTS.md`](./build/AGENTS.md)）。

- [`cheatsheet/`](./cheatsheet)（任意）
    - 学習記録ではない、素早く引ける操作コマンドのメモ集。
