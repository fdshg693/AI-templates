# 判断軸（scope 共通）

scope に依存しない、自分の選び方の軸。scope 固有の条件（予算・必須機能）は各 scope の `criteria.md` に書く。

## 重視すること

- **ロックインしない**: データを再利用できる形で持ち出せること。
- **運用の手間が小さい**: 自分たちでサーバーを持たないで済むこと。

## 避けること

- 料金体系が頻繁に変わるサービス。
