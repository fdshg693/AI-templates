# フェーズ状況

このファイルは、3フェーズのうち現在どこで、何を進めているかを一覧で管理する。各フェーズ内の計画の詳細、判断理由、未決事項は該当する計画ファイルを正本にする。

更新は、フェーズを開始・完了・中断したとき、または進行中の作業単位が変わったときに行う。

## 現在のフェーズ

- フェーズ: `未開始`
- 作業中の計画: `未定`
- このフェーズで進めていること: `未定`
- 最終更新: `未記録`

## 状態の書き方

「状態」列には `未開始`・`進行中`・`確認待ち`・`完了`・`中断` のいずれかを書く。各状態と計画ファイルの `status` との対応は [plan-format.md](guides/plan-format.md#phase-statusmd-の状態との対応) を正本とし、`lint_repo_plans.py` が食い違いを検査する。

フェーズを完了にする前に、該当する計画に対話・検証・引継ぎを記録する。次の具体的な作業は [AS-IS](asis.md) から再開する。
