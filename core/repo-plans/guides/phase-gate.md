# フェーズ完了ゲート

計画の `status` を `complete` にする前に、次のチェックリストを計画末尾の `## フェーズ完了ゲート` 節へ貼り付けて確認する。1つでも満たせない項目は `- [ ]` のまま残し、`complete` にしない。`lint_repo_plans.py` は `complete` の計画にこの節があり、`- [ ]` が残っていないことを検査する。

## 共通チェックリスト

- [ ] 計画に書いた完了条件をすべて検証し、結果（実行したコマンドと出力の要点など）を記録した。
- [ ] 初期案の提示、ユーザーの回答またはレビュー、反映（採否と変更箇所）を記録した。
- [ ] 回答が必要な質問が未解消のまま残っていない。残る未決事項は次フェーズへの引継ぎとして明記した。
- [ ] 実装中に仕様外の判断をした場合、[未規定事項の扱い](interaction-loop.md#未規定事項の扱い)に従って記録・確認した。
- [ ] 推測で埋めた値（担当者、期限、数値など）には「推測」と明記し、ユーザーが確認した値と区別した。
- [ ] `phase-status.md` と `asis.md` を現状に合わせて更新し、`lint_repo_plans.py` がエラーなしで終わった。
- [ ] 後続が読むべき決定・制約を、この計画の「未決事項と引継ぎ」に集約した。

## フェーズ別の追加項目

| フェーズ | 追加で確認すること                                                                                                                                                      |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1        | 目的・対象外・成功条件・最初の縦切りが揃っている。[質問の洗い出し](01-specification-and-technology.md#質問の洗い出し)の観点を一巡した。コードを書いていない。           |
| 2        | 利用者が再現できる実行・検証手順がある。最小の縦切りが動き、将来用の抽象化がない。                                                                                      |
| 3        | 移送した知見の参照先を計画に残した。ルール化は[基準](../AGENTS.md#ルール化とスキル化の基準)を満たす。ルートの指示ファイルから `repo-plans/AGENTS.md` への参照を外した。 |
