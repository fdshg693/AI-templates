# `worklog` リポジトリ立ち上げ完了記録

> [実行例の入口](../README.md) に戻る。これは実装済みの事実と検証結果を残す最終記録であり、新しい作業の指示ではない。

## 完了範囲

- 作業メモの追加と日付ごとの一覧を行う最小コマンドを作成した。
- 人が確認・修正できる一日ごとの Markdown を保存データの正本にした。
- 利用・検証の入口を README に、保存形式変更時の不変条件をエージェント規約に置いた。

## 検証結果

- 空データ、1件追加、複数日への追加、日付順・追加順の一覧を自動テストで確認した。
- 空本文と改行入り本文の拒否、日本語の読み書き（Windows、Mac の双方）を確認した。
- `## 午前` のように手で直した行を含むファイルでも、`list` が落ちないことをテストした。
- `add` と `list` の実行結果を利用者にデモし、日付見出しを追加した表示で合意した。

## 計画との差分

| 計画                       | 実際                                                                |
| -------------------------- | ------------------------------------------------------------------- |
| 一覧の表示項目は未決       | 回答で作成時刻を追加し、デモ後に日付見出しを追加した                |
| 保存先の指定は対象外       | 利用者向けには対象外のまま。テスト専用の `WORKLOG_DIR` だけ追加した |
| 形式外の行の扱いは未検討   | デモで一覧が落ちて発覚し、そのまま表示する仕様にした                |
| 検索は対象外               | 回答で要望が出たが、将来の候補に残した                              |
| スキルは作らない（初期案） | エージェントの提案を実績不足で見送った                              |

- 同期、共有、タグ、編集、削除、配布は対象外のままである。
