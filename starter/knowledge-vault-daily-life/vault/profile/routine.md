# 生活リズム

平日と休日の大まかな流れ。予定を提案するときはこの空き時間に合わせる。

|      | 平日                                   | 休日                                     |
| ---- | -------------------------------------- | ---------------------------------------- |
| 起床 | 6:00                                   | 7:00                                     |
| 朝   | 6:15〜7:00 ランニング（週 3〜4 回）    | 長めに走る（10〜15 km）か、パンを焼く    |
| 日中 | 仕事（出社日は 9:30〜18:30）           | 買い物・家事・カフェ                     |
| 夜   | 20:00 以降が自由時間。23:30 就寝が目標 | 月 1 回ボードゲーム会（第 3 日曜の午後） |

## 更新履歴

- 2026-10-01: 朝のランニングを週 2〜3 回から週 3〜4 回に更新（ランニングの digests より）。
