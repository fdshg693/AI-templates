# ランニング

## 1. きっかけ

- 2025-11 の健康診断で運動不足を指摘され、朝に 3 km から始めた。

## 2. 分かっていること

- 走るのは平日の出勤前（6:15〜7:00）と、休日の朝の長め（10〜15 km）。
- 記録はランニングアプリ。月の距離が見えると続く（[好み・傾向](../../../../profile/preferences.md) の「小さな記録が目に見えるもの」）。
- 雨の日と真夏の昼は走らない。代わりの運動として [ジム通い](../gym/index.md) を検討中。

## 3. 判断軸の確認・更新

- 質問: 「ハーフの後も今の距離を続けたいか、それとも元のペースに戻すか？」 → 回答: 「大会が終わってから決めたい」
- 反映: まだ `unverified_items` に置いている（2026-10-18）。

## 4. 今の状態・所見

- 大会まで 4 週間。9 月末に 20 km を走れており、完走は見込める。
- 気になること: 10/18 から右ふくらはぎに張り。1 週間続くなら整形外科を勧める。
- 次にやること: 11/1 の週から距離を落として調整に入る。
