# life — 日常生活

- 対象: 本人が続けていること・始めたいこと・通っている場所・仕事のプロジェクトなど、**繰り返し話題に出て、状態が変わっていくもの**を1件1フォルダで記録する。1回きりの出来事は、関係する対象のイベントログに書く。
- scope はこれ1つ。仕事と私生活で条件の前提（費用の負担者など）は変わるが、記録の目的が「本人の好み・近況を把握する」ことなので、分けずに `area` で分類する。

## area の付け方

| area       | 入れるもの                         | 迷ったとき                                                |
| ---------- | ---------------------------------- | --------------------------------------------------------- |
| `work`     | 仕事のプロジェクト・職場の取り組み | 仕事のための勉強は `learning`                             |
| `hobby`    | 趣味・創作・読書・ゲーム           | 友人と集まるのが主目的なら `people`                       |
| `health`   | 運動・睡眠・通院                   | 運動を兼ねた趣味は、本人が「健康のため」と言えば `health` |
| `food`     | 行きつけの店・料理・食の好み       | 作るのが楽しみの中心なら `hobby`                          |
| `home`     | 住まい・家事・ペット・植物         |                                                           |
| `money`    | 家計・投資・大きな買い物           |                                                           |
| `learning` | 語学・資格・習い事                 |                                                           |
| `people`   | 定期的な集まり・家族・友人との約束 |                                                           |

迷ったら本人に「何のためにやっているか」を聞き、主な目的で1つ選ぶ。もう1つの側面は `tags` に書く。

| ファイル                     | 役割                                                               |
| ---------------------------- | ------------------------------------------------------------------ |
| [dashboard.md](dashboard.md) | 直近の予定・最近の出来事・続けていること（自動生成）と今のフェーズ |
| [criteria.md](criteria.md)   | 新しく始めることの足切り条件（非公開）                             |
| [archive.md](archive.md)     | やめた・合わなかったものの台帳                                     |
| `entities/{key}/`            | 1件1フォルダ（index.md ＋ イベントログ）                           |
| `triage/`                    | 調べただけで候補から外したものの集約ログ                           |
