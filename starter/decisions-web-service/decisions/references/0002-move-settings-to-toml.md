# 0002 設定ファイルを TOML 形式に移行する

## 背景

[0001](0001-store-settings-in-ini.md) は「設定項目にリストや入れ子が2つ以上必要になったら見直す」としていた。v0.4 で同期先を複数持てるようになり、同期先ごとの `exclude` リストが必要になった（リスト2つ・入れ子1段）。INI ではセクション名に番号を振る独自規則が要り、利用者から書き方の問い合わせが3件来ている。対応 Python は 3.11 以上に上がり、標準ライブラリの `tomllib` が使える。

## 決定

設定ファイルは `~/.config/mdsync/config.toml` の TOML 形式にし、`tomllib` で読む。旧 `~/.mdsync.ini` は v0.5 まで読み込んで警告を出し、v0.6 で読まなくする。

## 検討した選択肢

### TOML（tomllib）

- 利点: 標準ライブラリで読める。リスト・入れ子・コメントを書ける。INI と見た目が近く移行しやすい
- 欠点: 標準ライブラリに書き込み機能が無い。設定を書き換えるコマンドを作るときに外部ライブラリが要る

### INI のまま独自規則を足す

- 利点: 移行作業が要らない
- 欠点: `[target.1]` のような規則を利用者が覚える必要があり、問い合わせの原因が残る

### YAML

- 利点: リスト・入れ子・コメントを書ける。書き込みもできる
- 欠点: 外部ライブラリが必要。0001 で挙げたインデント誤りの問題は変わっていない

## 結果

- 同期先ごとの設定を入れ子で書ける
- 旧形式の読み込みと警告を v0.5 まで保守する必要がある
- 設定を書き換えるコマンドが必要になったら、書き込み用ライブラリの採用を別の判断として書く
