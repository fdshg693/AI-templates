# 0001 設定ファイルは INI 形式にする

## 背景

CLI ツール `mdsync` に、同期先ディレクトリと除外パターンを保存する設定ファイルが必要になった。設定項目は現時点で4つ（`target`、`exclude`、`interval`、`dry_run`）で、すべて文字列か真偽値。利用者の大半は手で設定ファイルを編集する。

## 決定

設定ファイルは `~/.mdsync.ini` の INI 形式にし、標準ライブラリの `configparser` で読む。

## 検討した選択肢

### INI（configparser）

- 利点: 標準ライブラリだけで読み書きできる。書式が単純で、手編集で壊しにくい
- 欠点: リストや入れ子を表せない。`exclude` の複数指定はカンマ区切りの独自規則になる

### JSON

- 利点: 標準ライブラリで読める。リスト・入れ子を表せる
- 欠点: コメントを書けない。末尾カンマなど手編集で壊しやすい

### YAML

- 利点: リスト・入れ子・コメントをすべて書ける
- 欠点: 外部ライブラリが必要。インデントの誤りが別の意味として読まれる

## 結果

- 依存ライブラリを増やさずに設定を読める
- `exclude` はカンマ区切りで書く。パターンにカンマを含められない
- 設定項目にリストや入れ子が2つ以上必要になったら見直す
